## 4. 本轮已定位的 yaw 根因

1. 原控制器在收到跳跃请求和进入 `SQUAT` 时都把“当前 yaw”重新写成 `yaw_target`，会把每次漂移逐跳锁入。
2. 腾空后机构没有真实 roll/yaw 执行通道；一旦带着 yaw 角动量离地，空中无法靠轮电机消除。
3. 原起跳门检查车身和腿关节，但不检查左右轮速差；碰撞后残留 2～3 rad/s 差速也可能被带入下蹲。
4. 静止落地后对约 0.3° 的极小 yaw 误差做差速回正，会在球形轮胎粘滑区产生左右轮自激振荡。
5. MJCF 轮胎碰撞体是球体，对微小左右不对称和差速很敏感。诊断中仅 1% 左右执行器强度差就可以造成严重空中 yaw，说明原来的完美对称通过不具备压力代表性。

## 5. 当前控制中的 yaw 安全基线

`tools/wheelleg_sim.py` 仍保留以下 yaw 安全改动；第 0 节的低饱和 SQUAT 和速度恢复限制在此基础上生效：

- 只在用户主动转向时更新 `yaw_target`；跳跃请求和 `DRIVE -> SQUAT` 不再重置 yaw 目标。
- `jump_ready` 使用相对 `yaw_error`，不再限制世界绝对 yaw 必须接近 0。
- 直行 yaw 回正加入 0.5° / 0.05 rad/s 死区，避免球形轮胎粘滑自激。
- 静止跳后在 yaw 死区内对左右轮命令取平均；超出死区后仍允许差速回正。
- `JUMP_REQUEST_TIMEOUT` 从 1.2 s 实验性扩大到 3.0 s。
- `jump_ready` 的 yaw 角误差放到 0.5°，并新增左右轮速差阈值：动态 0.5 rad/s，静态 0.2 rad/s。
- `jp_pending` 时使用已有 `KD_WY` 对左右轮速差做差速阻尼，总 yaw 轮力矩限制在 ±0.08 N·m。
- `SQUAT/JUMP` 直行时仍强制左右轮命令取平均，避免高摩擦下差速控制自激。
- `SQUAT` 增加了实验性安全撤回：roll > 3° 或 yaw > 2° 时回到 `DRIVE + jp_pending`；角速率长时不稳定也撤回。
- SQUAT 关节速度阻尼使用 `KD_Q_SQUAT=0.10`，不再用会让四髋长期饱和的 `1.0`。
- 同向落速超过 0.05 m/s 时使用 `TW_DRIVE_RECOVERY_LIM=0.23 N·m`，其余行驶仍为 `TW_LIM=0.30 N·m`。

`tools/test_jump_stress.py` 已修正统计逻辑：

- 只在 `SQUAT -> JUMP` 时记录真正起跳速度；
- 只在 `LAND -> DRIVE` 时记录一次完整跳跃；
- `SQUAT` 安全撤回不再被误算为完成跳跃。
