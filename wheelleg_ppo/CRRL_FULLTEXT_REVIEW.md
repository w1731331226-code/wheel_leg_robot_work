# 受约束残差控制系列全文核对与本机方案影响

日期：2026-09-17。新增两篇已完成方法、稳定性前提、实验和复现条件核对；尚未复现作者实验。原优先三篇仍为2/3，不能以新增论文替换缺失的IEEE全文。

## 1. Adaptive control of a mechatronic system using constrained residual reinforcement learning

Tom Staessens、Tom Lefebvre、Guillaume Crevecoeur。阅读版本为[arXiv:2110.02566v1](https://arxiv.org/abs/2110.02566)，2021-10-06，9页；后续期刊为IEEE TIE 2022,69:10447–10456，本文只对实际取得的作者稿负责。[本地PDF](tools/results/legal_access_2026-09-17/crrl_2021_author.pdf)。

**方法与接口（第2～4页，II-B、II-C、III-B）**：SAC在PI控制曲柄滑块角速度的单输入力矩上学习残差。式2为绝对加性约束，式3为相对约束：

`u_total = u_base + β_a π(s)`；`u_total = u_base × (1 + β_r π(s))`，归一化策略通过tanh有界。

实验观测为角速度及角度的sin/cos，按标量计3维，动作1维。相对缩放保留在训练计算链中，作者讨论其按基输出幅度加权梯度的效果。基输出为零时，相对残差也为零（第6页讨论）；这限制了可达动作，不只是改变探索方差。

**稳定性究竟证明什么（第3～4页定理1/2、附录A/B）**：以机械系统M(q)q̈+B(q,q̇)q̇+g(q)=u和指定反馈律为基础，要求惯量正定、参考及初始误差满足界、相关矩阵范数可界定、控制增益和残差界满足充分不等式。结论是跟踪误差最终有界，不是任意系统、任意基控制器下的零误差收敛。理论使用位置误差及其导数的反馈表示；实验用角速度PI。不能只摘取“保持安全”而省略这些条件。

本机是欠驱动轮腿、多接触切换、VMC映射、状态机及执行器非线性限制，并未验证满足这些定理。因此该论文能支持“约束残差已有先例”，不能给本机提供现成稳定性证明。论文的理论SAC收敛讨论还区分表格情形与神经网络近似，不能据此保证本机PPO收敛。

**实验与预算（第4～7页、表II、图3～8）**：真实曲柄滑块，至少5次run，展示均值与min/max，未给可直接复用的种子清单。基PI先运行65 epoch；每epoch为500个送至PC的测量点，不能在采样率未核实的情况下换算秒数。比较绝对/相对约束、不同残差界、不同PI整定和60/90rpm及正弦参考；训练目标基于速度MSE，结果也报告MAE。

CRRL配置：Adam，学习率3e-4，折扣0.97，batch256，replay1e6，Actor两层各32、Critic三层各128、ReLU，目标平滑0.005。纯RL对照使用不同学习率、折扣和Critic结构，且先用基控制数据预训练；不能将两者性能差全部归因于残差参数化，也不能套成本机“同预算PPO”结果。未确认作者完整代码、原始日志、采样频率与种子列表；目前是全文核对完成，复现未完成。

## 2. Optimizing Cascaded Control of Mechatronic Systems through Constrained Residual Reinforcement Learning

同一作者团队，Machines 2023,11(3):402，[DOI 10.3390/machines11030402](https://doi.org/10.3390/machines11030402)。已取得根特大学官方知识库的19页出版版本，[本地PDF](tools/results/legal_access_2026-09-17/cascaded_crrl_2023.pdf)。

**系统与动作（第8～11页，式14、第3节）**：仿真双感应电机驱动同一负载；速度PI、功率分配、两个电机的磁通控制组成三层/四输出结构。SAC同时学习四个残差，默认相对界β_R=0.2；并非轮腿机器人左右轮差模，也不是只在最终六电机力矩上叠加动作。

Actor有共享表征及按控制层级组织的输出头，训练中把基控制器作为不可训练层，计算前层残差改变后的后层基输出。积分等内部状态使基输出不一定能从瞬时系统状态唯一恢复，因此作者把基控制输出传给对应输出头。部署时仍须按层级获得实际基输出，不能理解成删掉基控制器后独立运行网络。

**观测与实验（第11页、第4节）**：当前/前次总力矩参考、两电机前次力矩参考、开关标志、实际/目标速度、两电机估计定子磁通；原文列组成，未给展开的固定维度向量。每1.5s读状态并施加动作，基速度PI为50Hz；不能照抄其频率用于本机50Hz策略/2kHz控制。

训练轨迹5h30，评估轨迹1h，20次独立训练/评估，部署用Actor均值；epoch75s。这些是模拟轨迹时间，不是训练墙钟时间。按1.5s间隔计算，5h30约对应13,200次动作决策，但不等于梯度更新次数，也不能代替正式训练循环定义。

多输出配置：Actor学习率3e-5，Critic3e-4，折扣0.91，batch256，replay1e6；共享Actor两层各64，每头另1层；Critic三层各128，目标平滑0.005。单输出对照的网络宽度与Critic学习率不同，比较时需披露。消融包括独立/顺序训练、停止部分梯度和无层级结构的四输出网络，另考察残差界与测量噪声。

**理论与证据边界（第5～8、16页）**：第2.3节明确是线性频域分析，以闭环传递矩阵和最大奇异值讨论参考跟踪、扰动抑制及多层放大。对弱非线性系统是作者的设计外推，不是任意接触切换系统的全局定理。本文验证为双电机高保真仿真；数据声明为因限制需申请，未确认可公开运行的完整实现。附录提供模型参数，但不等于代码/数据完全开放。

## 3. 与当前实现的具体差别

核对对象为tools/ppo_env.py的Residual.map/apply、tools/wheelleg_sim.py最终输出链及PAPER_PLAN.md，不改运行代码。

| 比较项 | CRRL系列 | 本机当前实现及可写结论 |
|---|---|---|
| 动作形式 | 绝对加性或相对基输出缩放；串级有4路不同层输出 | ΔF/ΔT/Δτw先差动分配、再按当前VMC映射到电机空间；属于结构化加性动作子空间 |
| 约束依赖 | β_a固定绝对界，或β_r乘基输出 | 固定物理动作尺度加当前转速/名义力矩余量的公共λ；不是论文的相对CRRL，也不是学习出来的自适应安全边界 |
| 基输出为零 | 相对残差为零 | 在DRIVE且基输出可行时，只要余量充足，非零差模动作仍可执行；不把“零基输出”当作必须零补偿 |
| 插入位置 | 最终输出或各串级层参考/输出 | 六状态覆盖后、最终执行器限制前；三个动作并不构成三个串级学习器 |
| 稳定性 | 特定机械系统的充分条件，或线性频域分析 | 目前只有输出约束与给定仿真回归；无可继承的闭环安全证明 |
| 对照解释 | 有结构、网络和超参数差异 | 本机仍用共同修订B0、统一预算与物理空间奖励；自建CRRL式对照须标明adaptation，不能宣称复现原论文 |

据此，本机不能以“经典控制+RL”“残差限幅”“状态相关余量”独立主张创新。仍待验证的核心是：不对称接触下，差动动作子空间在共同强基线、同映射与预算下是否改善控制/学习表现。未做同维非差模对照，只能归因于参数化整体。

不立即增加串级多头网络或替换SAC：本机没有多个串级学习器，且用户目标是PPO方向；先验证已有差模假设。原有B2/B2-V/M及同维消融足以承担当前比较职责，不能为了引用论文新增未必要的模块。

## 4. 新发现的实验继续门冲突

最新final/baseline.json显示B0在validation_0..11为12/12。原第4周继续门要求M比最佳B0/B1/B2/B2-V成功率高至少10个百分点；最佳对照成功率至少100%，故原门当前不可达。这是修复强基线后出现的研究设计天花板，不是PPO程序错误。

保留原12例及28例作回归，不降低B0、不放宽成功阈值、不移动最终测试集。下一步候选是先用独立预注册的开发扩展样本评估剩余困难度（不是挑选失败样本），再决定是否存在值得学习的问题；若强基线在目标分布仍饱和，应接受缩题/改变研究问题。若转为连续指标研究，必须在训练前明确改题并重新预注册主指标及效应门槛，不能在看过学习结果后用yaw RMS替换原成功率门。

本次仅标明冲突并修正过时文档；未重定义数据划分、执行新难例筛选或启动长训练。
