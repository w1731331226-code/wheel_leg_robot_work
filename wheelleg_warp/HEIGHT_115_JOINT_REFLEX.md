# 0.115 m关节角预测制动：与径向反射配对

[独立被动链记录](results/height_115_passive_20260928/verification.json)显示14/14公开0.115 m轨迹主动关节会越过模型±1.5 rad软限位，且关节越界与腿长越线时刻并不总相同。高速平地首次越界附近主动关节角速度约9 rad/s，从1.4到1.5 rad约11 ms。[已拒绝的径向反射](HEIGHT_115_SAFETY_REFLEX.md)只补腿长，不直接阻止关节角越界；本轮只测一项新增机制，旧径向规则及用户0.115 m名义目标不变。

每个2 kHz控制步按已有主动关节角 `q`、角速度 `dq`，令外向速度 `v_out=max(sign(q)×dq,0)`。若 `|q|+0.020×v_out>1.45 rad`，在原髋命令及固定径向反射之后，追加朝关节中心的力矩

`T_guard=−sign(q)×clip(100×(|q|+0.020×v_out−1.45)+2×v_out, 0, 20) Nm`。

然后再次按原电机 `allowed(speed, hip)` 上下限裁剪。此项不改轮命令、不看地形真值，在静止0.115 m名义姿态（主动角约±1.049 rad）不触发。20 ms预测、1.45 rad启动、100/2系数、20 Nm上限只测试一次；这不是已部署控制器或实机安全保证。

同一图内每个原公开场景跑零动作、已拒绝径向反射、径向＋关节角制动三臂。固定14个基础场景及首回合；比较原任务门、主动FK和真实A链轮心全程不低于0.114704466 m、八关节不越模型限位，并记录A/B闭链误差、额外请求/执行力矩及电机裁剪。若组合臂六个正常场景未全部通过联合门，即停止该候选，不调阈值和增益；单侧障碍仅报告机制差异，不开启PPO或最终留出。

## 实施结果与继续判断

[同图逐例记录和源码哈希](results/height_115_joint_reflex_20260928/verification.json)显示：零动作、仅径向、径向＋关节三臂的正常六例联合门分别**0/6、0/6、1/6**，全部14例分别**0/14、0/14、1/14**。组合臂通过的是平地正向1 m/s；其余仍有径向代理线越界。相对仅径向臂，组合臂最差八关节余量从约−0.06786 rad变为**+0.01137 rad**，14/14没有主动或被动关节越限；关节修正最大请求约17.9 Nm、原电机包络未裁剪。本次最坏真实A链轮心腿长仍约**0.10110 m**，低于0.114704466 m；平地0.5 m/s实际轮心最低约0.114680 m，仍差约0.024 mm。记录的关节角速度“约9 rad/s”来自旧2 kHz位置轨迹差分，并非实机测速。

按固定六正常场景门停止该组合候选，不搜索阈值、力矩或持续时间。关节角越界可被这条仿真制动消除，但不能据1/6把新名义范围称为可稳定执行；下一步需把径向长度和关节角作为**同一个**可行域问题处理，验证真正的电机可达集合/机身运动，而非继续叠加独立经验阈值或改PPO。
