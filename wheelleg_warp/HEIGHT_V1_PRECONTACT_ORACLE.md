# height-v1 20 mm 单侧接触前受限动作上界

只使用公开[20 mm边界48例](results/height_scope_recheck_20260928/boundary_run1/verification.json)。先在同批零动作回放记录各世界首次凸台接触所在50 Hz采样时间；然后在**该时间前100 ms至后50 ms**，仅向原 M3 第三通道请求 `+sign(速度)` 或 `-sign(速度)`，分别完整评估一次。幅度固定为动作绝对值1，原0.01/0.5 ms动作滤波、共同λ、名义电机边界、姿态/速度/停车/高度门全保留，不调时间窗或其他两通道。零动作同批再跑一次作背景。

接触时刻来自模拟器零动作轨迹，属于**特权预瞄上界**，不能称为当前Actor可得信号。只比较逐世界任务成功和首回合峰值；成功数若未达到先前[能力探针门](HEIGHT_V1_CAPABILITY_PILOT.md)的24/48，停止本次固定轮差矩预瞄搜索，不据最低单例峰值追调。若超过门，才做重复、共同世界重排和120例原能力回归，再讨论真实预瞄来源。27 mm外推和最终留出均不使用。

## 执行结果与新假设边界

[原始逐例记录](results/height_v1_precontact_signblind_20260928/verification.json)为零动作17/48，两种不看侧别的符号各20/48，均未达预定24/48探索门，故不再调本协议时窗/幅度。事后逐侧拆解才发现左侧障碍适合`+sign(速度)`、右侧适合反号；这是**新假设的来源**，不能将本协议20/48包装为已验证的侧别策略。后续仅在独立[侧别条件协议](HEIGHT_V1_SIDE_ORACLE.md)中检验，并与无预瞄任务分开。
