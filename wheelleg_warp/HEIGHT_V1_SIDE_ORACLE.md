# height-v1 侧别条件接触前动作：新公开开发检验（运行前固定）

先前[不看侧别的双符号探针](results/height_v1_precontact_signblind_20260928/verification.json)各20/48；逐侧拆开后，`+sign(速度)`在左侧障碍20/24、右侧0/24，反号恰好相反。这产生一个**事后提出的新假设**：若提前知道障碍在哪侧，原M3第三通道可能守住更多训练范围内的20 mm任务。旧48例只是提出假设，不能当独立验证。

## 不随结果改变的测试

- 首先同批重放旧[20 mm边界48例](results/height_scope_recheck_20260928/boundary_run1/verification.json)，再用新公开开发种子 `1138000～1139999` 建一批独立的48例：在 `sample_scenario('train', seed,3)` 中按固定顺序取每个“左/右侧×正/反方向×低速(<0.75)/高速(≥0.75)”格的首个**单侧16～20 mm**场景，共8个基础场景；每个场景配六档0.16/0.20/0.25/0.30/0.35/0.38 m目标。只按参数选种子，不看成功率。
- 每批先零动作记录首次目标侧碰撞所在50 Hz时刻。侧别条件动作固定为 `sign(速度)×(+1 左 / −1 右)`，幅度1、仅M3第3通道。两种特权时序各完整测试一次：**预瞄**从零动作碰撞前100 ms到后50 ms；**接触触发**从碰撞时到后150 ms。两者持续150 ms，原0.01/0.5 ms滤波、共同λ、名义电机、5°姿态、速度、停车和腿长门均不改；不试更多幅度、时窗或动作通道。
- 两种触发都使用模拟器碰撞时刻和障碍侧别，是上界，**不是当前32维Actor可得信息**。记录逐世界成功/失败、按高度最差组、接触证据和峰值，不把单一成功数当方法优势。新批若不稳定超过同场景零动作，停止此固定脉冲；若预瞄显著优于接触触发，下一阶段才研究可实现的预瞄信息并做强经典对照。旧最终保留集不打开。

## 执行结果

[两批及共同反序的逐世界记录](results/height_v1_side_oracle_20260928/)显示旧批零动作16/48、预瞄两轮分别39/48和40/48、接触后触发20/48；新独立公开批零动作26/48、预瞄两轮均46/48、接触后触发25/48。预瞄相对同次零动作无逐例成功回退，但仍有失败且依赖特权信息。现有32维观测的[左右配对审计](results/height_v1_side_observability_20260928/)表明首次接触前左右场景的差值与相同场景数值背景同量级。结论和论文边界见[预瞄方向审核](HEIGHT_V1_PREVIEW_DIRECTION.md)；本协议不晋升为现有策略效果。
