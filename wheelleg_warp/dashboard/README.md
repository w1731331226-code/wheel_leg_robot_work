# 1024原生训练观测台

地址：`http://127.0.0.1:8765/`。页面只有原生并行基线。正式切换以前显示准入验证状态；预检画面明确标为预检，数据过期显示实际年龄。

- **总览**：全部1024世界的真实刚体位置、方向和轮子转动，以32×32姿态投影显示。每格跟随自己的机器人，点击或输入0～1023可选择详情。总览约10Hz，来源是训练GPU状态，不独立运行仿真。
- **详情**：训练进程中被选世界每5个物理子步采集一次，400Hz；独立渲染目标50FPS、960×540。使用真实子步缓冲，不插值造帧。显示实际浏览器帧率、原始帧编号、回合、仿真时间及源状态延迟。图像和元数据原子打包，避免切换环境/回合时错配。
- **暂停**：采样因PPO更新或评估停止时，缓冲耗尽就停在最后真实帧；不会另跑策略伪装直播。
- **录像**：只归档世界0的完整400Hz轨迹；全部环境都有实时总览与可选详情。录像取真实帧生成50FPS WebP/GIF，明确标为历史回合。优先WebP，编码进程独立于实时渲染。
- **状态**：本轮新增步数与继承检查点步数分开；吞吐包含采样和PPO更新，不把旧步数算作新速度。轮次、PPO更新次数、最佳开发成绩、停滞计数和独立终评均来自落盘记录。

训练端为 `native/live.py`；可视化不修改物理、控制、动作、奖励或成功条件。总览读取MuJoCo前向刚体姿态，最多落后对应积分状态一个0.5ms物理子步。详情直接使用记录的qpos/qvel/ctrl。背景、照明与地面反射只在独立渲染模型中调整。

正式目录为 `results/formal_native_1024_20260921/`，真实帧在各轮 `round_*/live/`，录像在 `dashboard/local_data/captures/native/`。原始轨迹/录像本地保存并由Git忽略，策略、协议、评估与代码进入Git。旧运行资料只在效果准入通过后按用户要求清理。
