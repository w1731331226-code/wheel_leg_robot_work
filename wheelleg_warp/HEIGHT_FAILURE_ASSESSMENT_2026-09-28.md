# 0.16～0.38 m 多高度单侧障碍失败机理复核

> **适用范围重评：** 本页 27 mm 单侧障碍属于论文规定的 25/30 mm **范围外推压力**，不能作为 0～20 mm 多高度训练的前置通过门。主任务的新配对证据与执行顺序以[多高度范围重评](HEIGHT_SCOPE_REASSESSMENT_2026-09-28.md)为准；本页保留其物理失效机理，不改写原始失败记录。

## 范围与证据

本轮只使用公开工程场景：左侧 27 mm 障碍、速度 ±0.5 m/s、目标腿长 0.16/0.20/0.25/0.30/0.35/0.38 m，同批 12 世界。未使用原 720000 留出集、未训练新 PPO、未改默认控制器或电机名义限幅。原始证据为[修正后的 50 Hz 控制输出](results/height_contact_execution_v2_20260928/)、[两次 2 kHz 物理轨迹](results/height_contact_2khz_v1_20260928/)及[受限控制对照](results/height_reflex_probe_v1_20260928/)；每份摘要保存所用源码 SHA256。历史 [50 Hz 初报](results/height_contact_timing_v1_20260928/REPORT.md)已附更正，原始 JSON 保留。

## 失败从哪里开始

| 触障后的事件 | 两次 2 kHz 回放中的范围 | 证据含义 |
| --- | ---: | --- |
| 左轮首次无任何碰撞接触 | 32–37 ms | 左轮与地面的接触累计仅 5–6.5 ms；直到偏航越界，左轮无接触累计约 43–54 ms，右轮持续接地。左轮与障碍的接触是间歇的，不能把累计次数称为连续接触时长。 |
| 左轮速度跨过电机额定 490 rpm | 45–53 ms | 触障时两轮约 96 rpm；左轮迅速空转，右轮速度仍较低。 |
| 基础指令不可行、共同残差系数 λ 首次归零 | 48.5–56.5 ms | 此时左轮约 585–598 rpm、右轮约 62–110 rpm。模型按轮速降低左轮可用力矩；一侧基础指令不可行使全部 M3 残差同时被抑制。 |
| 偏航首次超过 5° | 79–94.5 ms | 越界前左轮名义允许指令最低约 0.35–0.41 Nm。脚本用同一物理步开始时的轮速核算指令边界，未发现越界。 |

偏航在左轮首次无接触时已达约 1.08–1.69°，在 λ 首次为零时已达约 2.2–2.92°。因此，**单侧接触已先产生偏航扰动；左轮失去接触后快速空转，轮速退额与共同 λ=0 再削弱后续修正能力**，这比单称“PPO反应慢”更符合观测顺序。六档高度的腿长跟踪误差在修正的 50 Hz 对照中最大约 0.00043 m；先前六档×四类中等场景 24/24 成功，不能把本批失败归咎于高度目标没跟上。

## 逐项排除与尚未排除

1. **不是单纯的 50 Hz 才看见信号。** 2 kHz 可得 gyro 反射于接触后约 1–2 ms 请求并执行轮残差；特权接触触发约 0.5 ms 即执行，两者 12/12 均未守住 5°。正反两个轮差矩符号也各 0/12。它们只检验原 M3 第三通道、原 0.3 Nm 幅度和固定规则，不能否定所有反馈律。
2. **滤波值不等于电机作用。** 原 50 Hz 反馈的滤波动作在接触后 20/40/60 ms 约为 0.4/0.8/1，但实际执行轮残差起初只有约 0.12/0.24 Nm，此后常被 λ=0 抹掉。原报告称反馈使基础轮指令提前在 20–40 ms 限幅，是把限幅前基础指令和含残差最终指令错比；同次基础指令的正确结果是基线、反馈组均约 40–60 ms。
3. **右轮有空间，但粗糙转移不是答案。** 特权接触后只给右轮 0.3 Nm，12/12 失败；把右轮直接推到其名义速度边界也 0/12，另有 5 例跌倒。按左轮限幅缺口直接补给右轮仍 0/12，另有 5 例超时。大幅右轮控制可改变部分世界的后期偏航，却损害其他世界的姿态或前进；不能将单次峰值下降当任务成功。以上直接右轮方案属于**新分配方式的工程上界**，不是原 PPO 可输出的 M3 动作。
4. **接触力与模型滑移已有后续量化，实机机理仍未封闭。** 后续[载荷轨迹](results/height_contact_load_v1_20260928/)在相同12例、两次回放中测得左轮再次接触时法向峰值约190–211 N，载荷加权切向相对速度峰值约3.65–3.78 m/s；右轮法向载荷始终至少约23.6 N。MuJoCo直接电机的实际力矩与已限幅指令最大差约2.3e-7 Nm。这确认了**仿真中**间歇失接触、再接触高滑移和力矩执行链，但未测实机电流，也不能将单个接触冲量或具体摩擦系数定为唯一根因。

## 后续单因素检验：防空转不等于守住航向

只预先固定一条可得信号规则：在2 kHz测得左轮轮缘速度超过 `2×max(|车体前向速度|,0.2 m/s)` 时，令左轮电机指令为零；另以模拟器法向载荷不超过1 N时令左轮滑行作特权上界。其他控制、姿态/停车门与电机名义边界不改。原始首回合和物理子步见[防空转配对记录](results/height_antispin_probe_v1_20260928/)；`a0a/a0b`为两次原控制，`a1a/a1b`为两次可得规则，`a2a`为载荷上界，`a3a/a4a`分别在两种滑行触发上叠加前述固定2 kHz陀螺修正；`c*`为平地/对称台阶的正反方向、六档高度对照。

| 条件 | 单侧27 mm，12例成功 | 正常地形，24例成功 | 物理效果 |
| --- | ---: | ---: | --- |
| 原控制 | 两轮各0/12 | 24/24 | 左轮越界前峰值约690–693 rpm，λ=0占约34%–40%的接触至越界子步。 |
| 可得轮速/车速滑行 | 两轮各0/12 | 两轮20/24、21/24 | 左轮峰值降至约170–194 rpm，λ=0降至0；但偏航仍越5°，正常场景出现3–4例新增失败。 |
| 载荷特权滑行 | 0/12 | 24/24 | 左轮峰值约96–134 rpm，λ=0降至0，仍无法守住单侧接触姿态。 |
| 两种滑行各叠加固定陀螺修正 | 各0/12 | 未做候选晋升回归 | 切断空转并恢复残差余量，仍未通过同批任务门。 |

可得规则在24个正常场景均发生过触发；若干失败世界在减速停车阶段首次触发，表明简单的轮缘速度/车速比值也会把正常制动误判为空转。载荷oracle同样不是可部署检测器，虽保住正常场景，仍不能解决单侧障碍。本轮**停止调整这个倍数阈值**。更重要的是，防空转已几乎消除左轮超速和λ=0，偏航仍越界：空转退额是放大/限制恢复的机制，不是单侧碰撞后最初偏航的充分解释；若把论文问题直接写成“防空转后PPO即可恢复”，证据不支持。

## 决策与下一步

优先研究**首次碰撞至左轮脱离接触的前32～37 ms内，非对称法向冲量如何激发偏航，以及六路电机在原速度力矩包络下能否提前改变支撑**。下一项应先做完整可恢复前缀上的短时受限可达性上界，而不是再调轮差矩脉冲或轮速阈值：优化目标先固定为不越原5°门，并同时保留前进、停车和左右接触证据；若上界仍失败，转向机械/任务范围评估。只有上界可重复成功，才设计可获得的预瞄/接触状态与相应强经典控制，再考虑独立多高度PPO训练。原CPU历史结果、默认控制器和最终留出保持不动。
