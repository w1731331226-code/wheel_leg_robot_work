# 0.115 m低位安全反射：单项受限候选

此协议只检查当前0.115 m名义目标的几何余量问题。[工程门](HEIGHT_115_ENGINEERING.md)显示14/14公开2 kHz零动作轨迹越过0.114704466 m模型代理线，部分软关节限位也被穿越；首次越线在平地加减速时出现，故先研究可由原关节状态触发的2 kHz反射，不加PPO或前视信息。候选是独立诊断图的电机输出叠加层，默认控制器保持原状。

## 固定动作

每侧用现有主动关节FK得到腿长 `L`、极坐标雅可比得到径向速度 `dL`。仅当 `L + 0.020×min(dL,0) < 0.114704466 m` 时，请求额外向外虚拟力

`F = clip(500×[0.114704466−L−0.020×min(dL,0)] + 500×max(−dL,0), 0, 40) N`。

按原VMC雅可比映射至该侧双髋，与已算出的基础命令相加，最终逐电机按原 `allowed(speed, hip)` 力矩–转速界限裁剪。没有静态腿长抬高目标：在 `L=0.115 m、dL=0` 时 `F=0`。固定20 ms预测、500/500系数和40 N上限只测试一次，不据结果改阈值或增益。记录请求/执行增量、限幅、实际2 kHz主动与被动链长度、闭链误差、全部关节限位、姿态和原任务门。此层不是现有M3策略能力或实机安全控制器。

## 比较与停止

同一公开0.115 m面板含平地/20 mm对称台阶/3°横坡/4 mm粗糙路、平地±1 m/s和单侧20 mm左右×四速度，共14个基础场景；各配零动作与反射，首回合、原任务目标和0.114704466 m代理线不变。先要求六个无单侧障碍场景**全部**保持原任务成功且全程双腿不越代理线、八个关节不越模型限位；若不过门，报告哪一门失败并停止该候选，不以单次失败否定其他有界控制。只有此门通过才分析八个单侧障碍相对零动作的增减，不开最终留出、长训或PPO改动。

## 执行结果与停止

[同图逐场景结果及源码哈希](results/height_115_safety_reflex_20260928/verification.json)：基线与固定反射的原任务＋主动FK／真实A链轮心／八关节联合门均为**0/14**，六个正常场景均**0/6**。反射确实触发，最大请求40 N、限幅后髋命令相对基线最大变化约2.23 Nm，28个配对世界中反射臂未发生髋电机包络裁剪。最坏主动FK腿长从约0.095439 m提升到0.101120 m，但仍低于代理线；平地0.5 m/s实际A链轮心最低约0.114575 m，比代理线低约0.129 mm，八关节限位仍有越界。原基线最深关节余量约−0.06779 rad，反射约−0.06786 rad；现有几何/角限失败不能归因于本次髋命令被电机退额抹去。

按固定停止门拒绝这条20 ms预测径向反射，不再调其系数、上限或阈值；它的部分腿长改善不构成完整任务能力。下一项应分离低位俯仰／关节角空间约束和径向余量，先解释为何关节越界常早于或晚于腿长越线，再选另一种控制/机械止挡机制。不能仅提高恒定控制腿长参考来把0.115 m任务变成较高站姿。
