# 系统审查确定性错误修复与验收

## 结果

按优先级完成了任务出口/停车/成功一致性、延迟历史、批量参数、正式选模及冻结验证的修复。没有训练或更新策略，没有覆盖历史结果，也没有打开新留出集。

最直接的闭环证据：使用原terrain-v3检查点，重放已公开的15个受影响mixed场景，修正版任务下 **15/15完成、15/15实际接触、15/15双轮退出真实尾端、15/15成功**。这证明原策略在修正行程后确实能走完这些案例，不是新增训练收益或泛化验收；不能据此改写旧47/64。

## 按优先级完成的修复

### 1. 几何、停车与通过证据统一（任务契约v2）

- 删除按地形名称手写出口常量，直接读取每个世界实际静态盒体的位置、旋转和尺寸，计算沿行驶方向的真实末端，包含倾斜盒厚度与进出过渡坡。
- 停车目标至少超过实际末端0.15m，时限随目标更新；车身到达目标但轮子未退出时，不提前进入停车阶段。mixed末端现在约为中心后1.021m，不再是0.35m。
- 物理成功及±10奖励现在包含目标地形接触、双轮退出和原姿态/速度/停车条件。出口证据在终止物理步冻结，后处理与评价读取同一结果。
- 轮心按真实alpha/passA关节链、编译后的偏移和步末机身姿态计算，不用理想闭链近似，也不依赖滞后的`geom_xpos`。拓扑前提有显式检查。80个轮点对CPU运动学最大误差4.17e-8m。
- 所有终态与动画标签带`task_contract_version=2`。正式训练、目标试验和地形短探针统一验证该版本与通过证据；旧记录不能直接当新判据成绩。偏航指标按实际任务目标修正参考时长，CPU旧评分代码不变。

### 2. 延迟历史按实际需要分配

历史容量为本批最大延迟步数+1，写入、读取和重置使用同一数组长度。混合0/10/15/20ms批次为41格；第40个物理步正确读取40/20/10/0步，不再把15/20ms折为4.5/9.5ms。第1、20、40、41、80步及重置后的启动区间均通过检查。延迟仍按现有0.5ms物理分辨率量化。

### 3. 异质批量参数不再静默丢失

`stat.meaninertia`逐世界分配；共享求解选项逐项验证一致，不支持的差异明确拒绝。7/8kg的尺度分别为约1.394125/1.583790；迭代数、容差、Jacobian模式混用均被拒绝。GPU混合批次与两个独立世界的一步qpos/qvel差均为0；这不扩大为长期轨迹逐位等价证明。

### 4. 失败候选、原回归与显示链修正

- 未完整候选的空偏航指标用于内部排序时按无穷大处理，状态JSON使用null，不再报错；未完整候选正常归档并拒绝晋升。
- 晋升先检查逐场景保留已经成功的原场景，不能用地形进步抵消原能力丢失。全部新候选被拒绝时保留原最佳。
- 当前轮工作量和所选旧检查点分开记录，旧检查点步数不冒充本轮执行量；初始最佳作为回退时，仪表盘不再缺字段崩溃。
- 前端可显示空偏航指标，不再对null调用`toFixed`；补齐单侧坡/左右独立粗糙路标签，避免误显示为原场景。

### 5. 冻结输入真正执行校验

正式与目标训练运行前后验证任务版本、必要源码、模型ZIP、归一化PKL及协议是否改变；旧协议在构造1024环境前拒绝。正式初始化重新评估实际复制的检查点，不再复用历史`initial_evaluation.json`成绩。

上述是版本/内容一致性校验，不表示旧检查点文件自动满足新任务性能准入。下一轮仍须冻结正确的新开发/原回归/未公开留出协议，不能直接续跑旧协议。

## 未混入本轮的设计项

- 整车坡面的姿态目标仍需确认是世界水平还是局部支撑面；没有擅自改变控制/奖励目标，也没有改变5°/10°边界。
- 驱动差模型与真实扭矩硬上限的取舍未改变；新增`control_limit_scope=nominal_command`明确当前限制口径，不再把名义命令检查称作实际扭矩硬保证。
- 左右纵向错相仍是待实现课程项，当前`asymmetric_rough`仅高度独立；计划表述已纠正。
- 更长的同输入重复性误差定位、修正版完整基线与动作可达性仍待下一阶段。修复验收通过不等于正式训练成熟；本轮不继续λ分配试验或策略训练。
