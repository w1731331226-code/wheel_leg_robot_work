# 强成功率验收：六维虚拟力试验未通过

## 后续根因分析：先补因果证据，再做单因素尝试

后续2kHz失败链已完成，见[完整诊断](../failure_chain_20260922/REPORT.md)：八条固定策略开发回放确认首次5°越界到终端失败相隔0.7375～4.8700秒，奖励分解误差≤1.42e-14；入口轮速度限幅会全局清零残差，部分时刻仍有瞬时可行余量。未进行新训练或修改控制/奖励。下文“先补日志”已完成，下一步是单独验证失败反馈对齐；小批次结局变化不改写本报告原成功率。

用户要求先分析根因。本次只检查已有源码、检查点和历史结果，没有新训练、参数扫描或控制修改。结论是：尚未证明唯一根因，现有证据更支持优先核查**奖励与不可逆成功门的对齐**，而非继续扩大增益或动作维数。机器可读证据见`causal_analysis.json`。

### 1. 已确认：评价目标与训练反馈存在结构性不一致

成功要求全过程姿态峰值≤5°；越过该门后，即使恢复也无法成功。但是回合仍继续，直到横滚/俯仰40°、非轮接触、超时或到达后停车2秒才结束。失败统一终端−10，而姿态二次惩罚持续累计。峰值越界状态没有加入32维观测。

同一场景的历史例子：700302原策略完成但失败，未折扣回报−300.82；训练后提前跌倒，仍失败却得−18.37。700202也由完成失败−246.48变为跌倒−52.73。说明回报可能偏好更早结束坏轨迹，不能用回报改善代替成功率与完整率改善。

这不是已证明“策略学会投机跌倒”：两次策略的中间轨迹不同，PPO实际使用折扣回报/优势，现有记录不足以重建每个奖励分量和梯度贡献。总体困难组平均回报反而由−11.60变为−12.73，不能宣称训练已成功优化回报但牺牲了成功数。

### 2. 已确认：策略只能反应，无法直接预见台阶

观测包含机身姿态/角速度、速度/指令、腿关节状态、轮速、腿长及上次执行残差；没有障碍距离、高度、地形预瞄、接触状态或轮载。在其他条件相同且尚未接触时，不同台阶不会通过这些特征给出明确先验区别。

因此需要预先建立动量或调整姿态的行为不能依赖当前输入直接规划。它是否是限制成功率的决定因素仍需验证：反应式策略也可能足以处理某些高度，不能直接断言必须新增地形传感器。

### 3. 已确认：增加共模通道没有增加原有幅度权限

virtual6每腿径向残差最大3.4335N，腿力矩最大1N·m，每轮残差最大0.3N·m。腿长反馈刚度约3438N/m；仅按静态局部平衡估算，3.4335N相当于约0.999mm腿长目标偏移。六维能表达共模，但不能据此认为策略获得了足够大的越障姿态调节能力。

这是局部量级估算，不是总腿长运动范围，也不证明21～27mm台阶物理不可达。还需测量关键时刻残差实际可行域、受限电机和接触力，不能直接扩大力矩范围。

### 4. 检查点证据：实际优化量显著低于配置上限

六维204.8万步对应40个采样/优化周期，但保存的PPO计数为73个epoch，配置上限400；Adam实际更新11,197次，上限82,000。源码中`target_kl=.005`在近似KL>.0075时结束当次剩余优化，与该缺额一致。512k M3试验实际46/100个epoch、8,666/20,500次Adam更新。两者预算与数据不同，不能用这些数作算法优劣比较。

六维初始探索标准差约0.298/0.180/0.202（各复制两次），末点约0.301/0.184/0.205，并未塌缩到零；“探索完全消失”没有证据。缺少逐周期KL、clip fraction、value loss和explained variance日志，无法判断提前停止主要来自共享网络迁移、价值误差还是动作分布变化。不能简单放宽KL后宣称根因已修复。

每次rollout只有1秒（50策略步），gamma=.99、GAE lambda=.95。公式中的直接GAE衰减1秒约0.0466、2秒0.00217、3秒0.000101；跨rollout还依赖价值函数bootstrap。这不是实际梯度归因，也不意味着1秒以后的信息完全学不到，但说明延迟失败信号不能仅靠“采样步数足够多”保证学会。

### 5. 下一次尝试的顺序与停止门

先在固定开发失败/成功样本上记录完整时序：首次轮障碍接触→机身/轮速变化→策略反应→残差请求/实际执行/λ及具体受限电机→首次5°越界→最终结束，并分解速度、姿态、残差平滑与终端回报。现有轮速构造的滑移代理不能替代接触点切向滑移。

这段证据完成后，最先检验“不可逆失败信号及时反馈且回报排序不奖励更早跌倒”这一单因素假设；固定网络、动作模式、地形、指令、权限和PPO配置。评价继续跑完整物理轨迹，不放宽全过程成功门。只有证明该因素造成净收益，才分别考虑预瞄信息、权限或KL设置。

任何下一次训练前还应有困难场景可重复成功的控制证据；没有可达性证据时不继续堆预算。强验收仍是≥20个百分点提升、成功≥85%、完整≥95%、独立重复稳定、原能力不退化。当前只是完成根因分析，不是找到已验证的新优化方案。

## 验收标准

用户明确要求大幅提高真实困难场景成功率，并能够稳定保持。试验开始前将强门冻结为：相对同场景原策略提高至少20个百分点且成功率不低于85%，完整率不低于95%，原场景/坡面/进阶回归不退化；开发通过后才进行多个重复与独立测试，独立集不得用于重选参数。

本开发集原策略为33/48，因此候选至少须达到43/48成功和46/48完整；达到该开发门仍不代表最终验收通过。

## 最小结构性假设与实现

M3的三个虚拟残差都是左右反向，缺少独立共模支撑力、腿力矩和轮驱动力。项目CPU已有virtual6映射，本试验复用其六个独立虚拟力通道，并沿用原幅度、变化率及最终电机限幅。观测仍32维，主网络、控制器、地形、指令和成功门不变。

将M3动作输出行按`[F,-F,M,-M,T,-T]`复制到六维头，确定性策略输出测试与GPU差模嵌入回归通过；初始策略与原M3理论等价，不把初始化前后的仿真波动计作优化。因为动作维数改变，Adam重新初始化，不能称精确续训。VecNormalize观测统计保留，动作空间显式改为六维后保存。

随机探索变为六通道独立高斯，不能声称与M3具有相同随机行为。本试验只判断该预算内候选是否满足强门，不足以判定所有virtual6训练方案都无效。

## 结果

开发96例全部使用新种子700000起始：48个真实直立台阶、16原场景、16平滑坡面、16单侧坡/左右粗糙路。训练种子710000起始，1024并行，约60%困难台阶、30%原场景，固定2,048,000步预算、40次PPO更新。

| 条件 | 台阶成功 | 台阶完整 | 原场景/坡面/进阶 |
|---|---:|---:|---|
| 原M3 | 33/48 | 45/48 | 各16/16 |
| 六维确定性迁移起点 | 34/48 | 45/48 | 各16/16 |
| 六维训练1,024,000步 | 32/48 | 41/48 | 各16/16 |
| 六维训练2,048,000步 | 32/48 | 44/48 | 各16/16 |
| 速度受阻时同向腿力矩辅助，增益1 | 31/48 | 42/48 | 各16/16 |
| 同向辅助，增益3 | 33/48 | 43/48 | 各16/16 |

辅助试验没有学习，使用已有速度观测；当`abs(cmd)>.1`且`sign(cmd)*(cmd-v)>.08`时，将两侧腿力矩残差设为`clip(-gain*(cmd-v),-.7,.7)`，其余动作仍用原M3，未改变速度指令或地形。该直接可达性检查同样未显示大幅收益。

**所有候选均未通过，权重不晋升，独立留出720000尚未评估。** 增加可表达的共模自由度只是工程能力，不足以证明策略性能瓶颈已解决；不能以参数更多、训练步数更多或姿态均值下降代替成功率验收。

## 交付与边界

`residual_mode='virtual6'`仅作为显式实验选项，默认仍`diff3`；残差缩放默认仍1.0。无全局默认切换。`test_virtual6.py`验证差模嵌入、共同轮扭矩执行、额外状态重置及维数拒绝；原控制器回归另行核验。录制元数据带残差模式，8770页面显示1024真实总览/所选世界，试验完成后渲染停止，页面保留快照。

此前半残差96/144→98/144的结果已降为未通过消融，其文件改为`policy_minimal_20260922/rejected_configuration.json`。当前没有符合强标准的优化成果。后续需先证明困难场景的可达性、观测与控制权限足够，并找到可复现的成功行为，再开展有明确目标的策略学习；这些仍是待验证项，不宣称已找到唯一根因。
