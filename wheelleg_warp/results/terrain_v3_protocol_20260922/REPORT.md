# terrain-v3 冻结协议与准入

## 范围

terrain-v3复用16个统一拓扑geom，在原六类基础上新增连续四段坡、多级台阶和左右轮异高路面。课程前两轮优先原场景与混合地形，第3～4轮加入三类新地形，第5轮起使用完整分布；正式训练保持1024并行、每轮1,024,000步、连续3轮无改善停止、最多10轮。

新地形使用地形相对姿态门：局部横滚/俯仰误差与世界偏航均不超过5°，同时世界横滚/俯仰不得超过10°。非legacy地形必须记录左右轮地形接触；混合地形还必须满足对应左右障碍接触。旧v1/v2场景默认继续使用原世界坐标5°门，历史语义不改写。
