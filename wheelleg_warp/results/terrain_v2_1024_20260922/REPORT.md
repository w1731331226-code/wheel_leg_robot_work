# terrain-v1/v2 非结构化地形训练结果

## 2026-09-22 地形通过判据审计更正

此前 **55/64** 仅保留为历史运行记录，不再作为有效地形泛化证据。根因位于共享批量模型入口：各世界的 `Model.geom_pos/geom_quat` 虽不同，但 MuJoCo Warp 会从第一个 CPU 模型一次性初始化 world-body 静态 geom 的 `Data.geom_xpos/geom_xmat`，后续运动学又按设计跳过这些静态 geom。旧入口没有逐世界补写 `Data`，导致一个批次内所有世界实际使用第一个世界的障碍与地形位置。

最终64例批次的第一个场景是负向混合地形 seed 250000，因此其余63例也实际使用了该静态几何。原6个“未接触障碍”全部是正向场景；轮轨迹到错误运行时障碍的最近纵向距离为1.842～1.879m，不属于绕过、跨越或接触漏记。缺陷复现逐例得到相同的零障碍接触掩码；修正几何后6例均满足各自要求的障碍接触，最近纵向距离降至0.001～0.005m。逐帧轮轨迹见 `mixed_trace_audit.json`，代表场景真实物理重放见本机 `dashboard/local_data/terrain_audit/seed_250005_before_after.gif`。

共享入口现已逐世界初始化静态 geom 的位置与姿态；非 legacy 地形成功门新增左右轮地形接触掩码 `0b1100`，并输出 `required_terrain_contact_mask`、`touched_terrain_contact_mask` 和 `terrain_passed`。混合地形仍同时要求原左右障碍接触门。因此“完整到达任务终点但没有真实轮地形接触”不再计为成功。

使用旧检查点在同一批已公开64例上做缺陷修正诊断重放得到51/64：坡道13/13、横坡6/13、粗糙路13/13、台阶9/13、混合10/12；64例均完整且满足新增地形通过证据，13个失败全部只由世界坐标5°姿态门触发。该重放不是新留出验收，不用于选模或续训；详见 `terrain_gate_audit.json`。下一轮训练前必须先重建有效开发集/留出集，并完成修正后同场景配对回归。

该缺陷位于通用原生 GPU 批量入口，历史60/64原生基线及 terrain-v1/v2 中依赖逐世界静态障碍/地形差异的结论均需撤销有效证据地位并重跑；原 CPU 基准不受此 MuJoCo Warp 静态 `Data` 初始化缺陷影响。

## 结论

terrain-v1完成8轮、累计新增8,192,000策略步；terrain-v2修正组合几何后从v1最佳继续4轮、新增4,096,000步。两次训练均使用1024个MuJoCo Warp世界、M3策略、VMC＋六状态LQR、n_steps=50、学习率3e-5和target_kl=0.005。

terrain-v2最佳为第2轮末点：固定开发地形20/32、原场景回归11/16，Jψ分别0.530597°和0.549816°。第3、4轮没有超过该检查点，连续2轮停滞后停止。成功数没有提升，改善主要来自完整轨迹姿态精度；不能写成所有地形能力全面提高。

停止后首次打开terrain-v2的64例新OOD地形集，结果为 **55/64，全部轨迹完成，Jψ=0.586542°**。同期16例新IID原场景为 **11/16，Jψ=0.546294°**。OOD未用于选模、调参或追加训练。

| OOD地形 | 成功/总数 | 主要失败原因 |
|---|---:|---|
| 坡道3°～5° | 13/13 | 无 |
| 横坡3°～5° | 12/13 | 1例停车尾速超门 |

## terrain-v1协议问题及修正

terrain-v1 OOD为46/64，但包含一个无效子协议：组合地形0/12时，轨迹均完整且姿态、速度、停车指标通过。根因是12段粗糙块覆盖中央障碍区，较矮障碍可能埋在粗糙面下，而成功门仍要求接触对应障碍。因此0/12不能解释为策略失败。

修正后在同一12个v1组合场景上直接复测，成功由0/12变为6/12；成功场景的required/touched接触掩码一致。terrain-v2进一步使用全新开发和OOD种子，并在障碍中心±0.35m留出无粗糙块走廊。v1记录没有删除或改写。

terrain-v1其他有效OOD结果保留：坡道13/13、横坡13/13、粗糙路13/13、21～30mm台阶7/13。terrain-v2使用不同固定种子和续训策略，因此两版成功率只能说明各自冻结协议结果，不能把差值归因于单一代码改动。

## 学习与回归

terrain-v1开发集成功数在8轮内保持地形24/32、原回归13/16，Jψ和从1.811降至1.154。terrain-v2使用全新固定开发集，4轮内保持地形20/32、原回归11/16，最佳Jψ和从1.117降至1.080。曲线见 `convergence.png`；两条曲线的开发场景不同，不能横向比较绝对成功数。

训练范围仍只到3°坡、2～6mm粗糙度和5～20mm台阶；更大范围只作为OOD。现有成功门使用世界坐标5°姿态阈值，更陡坡进入训练前仍需地形相对姿态与沿坡停车指标。

## 工程与动画证据

- 旧NativeEnv回归、六类统一拓扑闭环、有限状态、非法动作拒绝通过。
- 修正后的102,400步探针完成2次PPO更新，权重和损失有限；首次预算断言失败完整保留，探针权重均未晋升。
- 原1024基线动画保留于 `http://127.0.0.1:8765/`；terrain-v1归档在8766，terrain-v2最终动画和录像在8767，三个数据根互不覆盖。
- terrain-v2完成后训练与渲染服务正常退出/停止，三个只读前端继续提供最终快照、录像、轨迹和最佳权重。

“最佳”仅指冻结开发集、排序、预算和停止规则下的最佳检查点。结果是纯仿真证据，不证明全局最优、方法结构优势或实机安全。
