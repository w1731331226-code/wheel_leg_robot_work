# height-v1 接触触发腿部差动支撑：一次受限反应式检验

问题：侧别预瞄轮差矩能明显改善20 mm单侧边界，但现有32维Actor没有可靠的碰撞前侧别；模型有左右轮接触力。先检验**首次接触后**仅靠原M3第1通道的差动支撑是否可能守住5°，不引入未来障碍位置。

固定面板为已公开[20 mm单侧×六档48例](results/height_scope_recheck_20260928/boundary_run1/verification.json)，不打开最终留出。2 kHz基础控制器看模拟器当前左/右碰撞位；首次碰撞后的下一物理子步开始，100 ms内第1动作通道请求 `+side` 或 `−side`，`side=+1`左侧、`−1`右侧；其余两通道为零。各符号一次完整回放，零动作同图一次。保持0.01/0.5 ms滤波、共同λ、名义电机速度力矩约束、任务的姿态/速度/停车/≤2 cm高度门。若两符号均未达到预定 **24/48** 探索门，停止此固定规则；若过门，才做重复、世界重排和正常地形回归。

模拟器碰撞位只是接触触发的工程上界；它不在当前Actor 32维观测中。即使通过，也须以可获得的轮接触力/估计器替换，并和已公开的[CTBC接触触发盲爬](https://arxiv.org/abs/2509.02986)等强经典方法配对，不能直接称为PPO创新。

## 执行结果

[逐世界验证](results/height_v1_contact_support_20260928/verification.json)为零动作16/48，两个相反符号分别15/48、18/48。两组48例均触发完整的100 ms窗（200个物理子步），滤波动作均值绝对值约0.75、平均执行腿部残差四路绝对值合计约0.49 Nm；动作不是被入口静默丢弃。两组均未达到24/48预定门，**停止此固定接触触发支撑脉冲**。这不否定CTBC式复杂抬腿轨迹或其他可得接触反馈，只说明原M3第1通道的这一条简单规则不足以复制[侧别接触前预瞄](HEIGHT_V1_PREVIEW_DIRECTION.md)的收益。
