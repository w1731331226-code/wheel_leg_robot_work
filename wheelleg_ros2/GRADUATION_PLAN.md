# ROS2毕设方向（暂缓执行）

2026-09-15用户确认：ROS2用于毕设，PPO用于论文，优先PPO。此项目是独立基线，不依赖论文项目后续代码，不要求PPO训练成功才能完成毕设。

建议题目：基于ROS2的轮腿机器人运动控制与导航仿真系统设计。

范围：以现有VMC＋LQR为底层，建立命令、状态、坐标变换和日志接口；完成ROS2节点通信、可视化、定位/建图与导航的分阶段集成。Nav2是否纳入最终验收需结合毕设时间和导师要求；不把能收发话题当作自主导航完成。

阶段：

1. 定义观测＋命令→六路力矩及频率、坐标、单位，仿真接口复现基线。
2. ROS2节点、TF、里程计、IMU、joint states、命令仲裁和急停/超时，RViz验证。
3. 接入仿真雷达，验证建图/定位，再接导航；先平面环境。
4. 记录任务完成率、轨迹误差、命令延迟和异常恢复，形成毕设报告与演示。

不声称当前已有ROS2包或实机控制。恢复该项目时再选择发行版和依赖；目前不安装ROS2、不建立空包、不迁移C++。ROS2上层不直接接管高频平衡环。

基线来源见BASELINE_MANIFEST.json；后续从PPO引入改动须逐项验证和记录，禁止覆盖同步整个控制目录。
